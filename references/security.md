# Seguridad y privacidad

- Autentica con un proveedor confiable.
- Autoriza cada operación en el servidor.
- Usa variables de entorno o un gestor de secretos.
- Restringe archivos por objeto, rol y vigencia.
- Minimiza ubicaciones y elimina metadatos innecesarios de imágenes.
- Evita datos personales en logs.
- Define retención y eliminación.
- Cifra tránsito y almacenamiento.

Antes de publicar, busca correos, teléfonos, URLs privadas, claves, tokens, identificadores largos, nombres propios, marcas, archivos multimedia y datos de producción. Sustituye ejemplos por valores sintéticos.
